# 🛠️ বাংলা টুলকিট (Bangla Toolkit)

সব দরকারি টুল **এক জায়গায়** — সুন্দর বাংলা ইন্টারফেসে। HTML/CSS/JavaScript দিয়ে বানানো, কোনো dependency নেই!

## ✨ ফিচার

| টুল | কী আছে |
|---|---|
| 🧮 ক্যালকুলেটর | যোগ, বিয়োগ, গুণ, ভাগ, বন্ধনী — সবকিছু |
| 📐 কনভার্টার | দৈর্ঘ্য (কিমি/মাইল/মিটার/ফুট), ওজন (কেজি/পাউন্ড/গ্রাম), তাপমাত্রা (°C/°F/K) |
| 🔐 পাসওয়ার্ড জেনারেটর | কাস্টম দৈর্ঘ্য, কপি বাটন, শক্তি মিটার — `crypto.getRandomValues` দিয়ে নিরাপদ |
| ✅ টু-ডু লিস্ট | ব্রাউজারে সেভ থাকে (localStorage), টিক/ডিলিট |

## 🚀 ব্যবহার

ডাউনলোড করে `index.html` খুলুন — শুধু এটুকুই! অথবা GitHub Pages দিয়ে ফ্রি হোস্ট করুন।
